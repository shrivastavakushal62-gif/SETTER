# SETTER - Gamified Productivity System

SETTER is a web-based productivity system that turns real-life tasks into a game. Users complete quests, earn coins, level up, and use rewards to stay motivated and disciplined.

## 🚀 Features
- Quest system (complete or miss tasks)
- Coin reward system
- Penalty for missed quests
- Level progression
- Shop system for upgrades

## 🎯 Purpose
This project is designed to make self-improvement engaging by applying game mechanics to daily life tasks like studying, workouts, and skill development.

## 🛠️ Tech Stack
- HTML
- CSS
- JavaScript
